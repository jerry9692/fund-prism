### 2.3 我方更优 / 思路不同（不计入问题，仅供参照）

- **动态归因**：对方服务端预计算；我方 Brinson(BHB/BF)+Carino 对数平滑 + 残差占比门禁，方法论更标准。
- **评分**：对方 14 因子固定 zs；我方 8 维 + winsorize/zscore/percentile + 缺失惩罚 + 样本期降权 + IC/IR 回测，可验证性更强。
- **交易能力**：对方依赖服务端预计算个股贡献；我方从披露持仓 + 行情自估换手/择时，且 `estimated_` 隔离。属"思路不同"。
- **估计值隔离/结论门禁**：对方无；我方 `credibility.py` 五道门禁 + 结论状态分级，架构级优势。
- **发现能力**（指纹/相似/异常/反向检索/池提醒）：对方完全没有，我方 Phase 3 独有。

## 4. 结论

1. **架构与数据模型**：双方底层同构，我方已覆盖对方"检索/视图/持仓/持有人/风格/归因/交易/评分"主线能力，并在归因方法论、评分可验证性、估计值隔离、结论门禁、发现能力上系统性反超。

2. **值得做的缺口，绝大多数是我方需求书自己的既定路线**：债基（§6.2.7）、指数/ETF（§6.2.8/§6.2.9）、画像频谱（§6.2.6）都写在四期 §12.4，优先级应由我方分期决定，老系统只是"佐证其价值"，不改变排期。

3. **真正的欠账是收益拆解**：§6.2.3 把打新收益、转债收益列为收益拆解的**本体维度**（非四期才做），我方却占位 0.0，应作为 Phase 4 最高优先级补齐。

4. **两处实现 bug**（anomaly top10 未排序、trading_ability 半年报假设）不占 phase，应立即修；另有 §6.1.4 一期就规划的基础指标（胜率/回撤修复天数/同类排名）一直未补，建议 Phase 4 前置补强。

5. **不建议照搬**的：ETF 组合构建爬山法（应复用我方凸优化）、研究报告库/PDF、权限/审计/加密、抱团度/内部认可度/规模逆向——要么需求书已明确排除，要么与我方定位或已有实现重叠。
